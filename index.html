🧪 Testing Instructions (End-to-End)

  1. Signup: Use the auth card → Create account (or Demo Login). JWT stored, redirected to Discover.
  2. Set location: Header shows approximate area (Bandra West ~1.2km). Change via profile if needed.
  3. Discover: Verify 8 activities sorted by Nearby. Filter by Sports/Food/Gaming, search "biryani".
  4. Join: Click Join on any card → Request sent → appears in My Plans → Joined & Chat.
  5. Create: Click Create → fill form → Publish → appears at top of Discover & in Hosting.
  6. I'm Free: Click I'm Free → pick intents (e.g., Cricket) → Tonight + 3km → See matches → Join one.
  7. Chat: Open Chats → select activity thread → send message → auto-reply simulates WS.
  8. Check-in: In My Plans → Joined → Check In (enabled) → confetti → Complete.
  9. Feedback: After complete → Rate 1-5 + comment → Submit → stored in PostgreSQL.
  10. Verify API: Open API Docs (this modal) → confirm all endpoints respond. Check Network tab for JWT.
✓ Pass criteria: signup → feedback in <2 min Test user: demo@whosin.app / demo123
